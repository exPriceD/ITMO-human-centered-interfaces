# Первый Python

Учебный сайт для лабораторной работы по человеко-ориентированным интерфейсам.

Работают поиск и фильтры курсов, описание с программой и нагрузкой, форма учебной записи и подтверждение. Курсы демонстрационные.

## GitHub Pages

В Settings > Pages выберите:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Нажмите Save. Адрес сайта: https://expriced.github.io/ITMO-human-centered-interfaces/

Сборка и установка зависимостей не требуются. Пути к файлам относительные, переходы между экранами используют hash-маршрутизацию.

## Яндекс.Метрика

Подключён счётчик 114507449. Идентификатор задан в config.js. Счётчик принимает данные с адреса этого сайта на GitHub Pages.

Параметр ?test=1 включает тестовый режим без отправки в Метрику. Страница diagnostics.html показывает локальный журнал событий для отладки.

Запись на курс учебная. Данные формы не отправляются на сервер. Не вводите реальные контактные данные.
